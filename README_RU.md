# FunTime ESP Observer

Экспериментальный экранный мониторинг подсветки ESP с уведомлениями Telegram.

## Установка
1. Установите Python 3.11+ с https://www.python.org/downloads/ (включите Add Python to PATH).
2. Установите Tesseract OCR для Windows. Если он не находится автоматически, добавьте в начало `app.py`:
   `pytesseract.pytesseract.tesseract_cmd = r"C:\\Program Files\\Tesseract-OCR\\tesseract.exe"`
3. Распакуйте проект и запустите `start.bat`.
4. Создайте Telegram-бота через @BotFather, отправьте ему /start и получите Chat ID (например, через @userinfobot).
5. Введите Token и Chat ID в окно программы.

## Что умеет
- анализировать цвета на экране;
- приблизительно обнаруживать фиолетовые/оранжевые ESP-подсветки;
- пытаться распознавать координаты в левом верхнем углу;
- сохранять скриншоты и отправлять уведомления в Telegram.

## Ограничения
Это прототип. Пороги цвета и область OCR могут потребовать настройки под ваш интерфейс. Возможны ложные срабатывания. Программа не двигает персонажа, не копает, не взаимодействует с сервером и не читает память Minecraft. Команды Telegram (/status, /last и т.п.) не реализованы.
