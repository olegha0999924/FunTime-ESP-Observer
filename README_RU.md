# FunTime ESP Observer

Экспериментальная программа для экранного ESP-мониторинга, чтения координат Minecraft Java и уведомлений Telegram. Дополнительное управление клавиатурой и авто-туннель предназначены **только для одиночного мира или собственного тестового сервера**.

## Установка

1. Установите Python 3.11+ с https://www.python.org/downloads/ (включите Add Python to PATH).
2. Установите Tesseract OCR для Windows.
3. Распакуйте проект и запустите `start.bat`.
4. Для уведомлений создайте Telegram-бота через @BotFather, отправьте ему /start и получите Chat ID.
5. Введите Token и Chat ID в окно программы.

## Возможности

- экранный поиск фиолетовой/оранжевой ESP-подсветки;
- попытка распознавания координат XYZ из F3;
- скриншоты и уведомления в Telegram;
- поиск окна Minecraft;
- ручное удержание W и ЛКМ;
- экспериментальный авто-туннель по прямой на высоте Y от -60 до 0 с выбором кирки/лопаты по распознанному блоку;
- контроль полоски прочности кирки в слоте 2 и попытка ремонта пузырьками опыта; масштаб интерфейса GUI читается из `options.txt` (для распространённых папок Minecraft), чтобы точнее находить слот 2.

## Управление

- **F6** — включить/выключить движение вперёд (W).
- **F7** — включить/выключить копание (ЛКМ).
- **F8** — аварийная остановка движения, копания и авто-туннеля.
- **F9** — включить/выключить контроль прочности.
- В окне есть отдельные кнопки проверки XYZ, ручного ремонта и запуска/остановки авто-туннеля.

## Раскладка для авто-туннеля и ремонта

- слот 2 — кирка с зачарованием «Починка»;
- слот 3 — лопата;
- слоты 6–9 — бутылочки опыта;
- вторая рука — пустая.

Для ремонта программа переключает кирку во вторую руку, бросает до четырёх бутылочек из каждого слота 6–9 по одной и затем возвращает кирку в слот 2. При прочности не выше 20% движение останавливается. Если после ремонта программа не может подтвердить прочность выше 20%, авто-туннель блокируется до ручной проверки.

## Ограничения и безопасность

- Авто-туннель экспериментальный: он зависит от видимости F3, OCR и распознавания Targeted Block. При потере распознавания, выходе за диапазон высоты или опасном блоке программа должна остановиться.
- Перед запуском убедитесь, что Minecraft находится в фокусе и раскладка инвентаря соответствует указанной выше.
- Не используйте автоматическое движение/копание на публичных серверах; тестируйте только в одиночном мире или на собственном сервере.
- Возможны ложные срабатывания ESP и ошибки OCR. Программа не читает память Minecraft и не гарантирует обнаружение объектов за стенами.
